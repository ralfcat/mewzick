# To run the bot

To run the bot you need to change the "bot_token" to your own personal bot token. To obtain your personal "bot_token", you'll need to create a bot
on the discord developer based and go from there. There are several tutorials on this available if you just google. Never give out your "bot_token" to anyone.

It is recommended to use a bot hosting service if you intend to have the bot on multiple servers at the same time. Finding a suitable one is a google search away :)


Have fun!
